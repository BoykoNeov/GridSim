# Evidence

The files the milestone docs cite as evidence — written-down predictions (made before
each sabotage ran), probe and spike scripts, gate captures, mutation runners, and
manifest copies from milestone closes. They lived in a scratch folder and were moved
here on 2026-10-08 so the citations in `docs/plans/`, `reference/` and `test/` point
at something that exists. Each folder keeps its original name, so a citation reads
`docs/evidence/<folder>/<file>`.

These are records of what was run at the time, not maintained code: many contain
the absolute scratch paths of the machine they ran on. The one maintained, runnable
set is `gridsim-m9/harness/` (see its README).

Left out on purpose: the source PDFs under `gridsim-m9/sogl/` (the regulation and
two ENTSO-E documents cited in `docs/plans/m9-context.md` D3) — only the text
extracts are kept — and every log, render and output nothing cites.

# Scenario data — Iberian blackout, 28 April 2025

Extracted reference data for building and validating GridSim scenarios against a
real, well-documented system event.

**Source:** ENTSO-E ICS Investigation Expert Panel, *Grid Incident in Spain and
Portugal on 28 April 2025 — Factual Report*, 3 October 2025 (264 pp.).
Page numbers below are the report's own printed page numbers.

All times CEST (UTC+02:00). This file holds **only** figures stated in the
report; anything derived is marked *(derived)* and shows its arithmetic.

---

## 1. System conditions immediately before the incident (12:30)

### 1.1 Inertia (Table 2-4, p.36)

The report computes stored kinetic energy `KE = Σ Hᵢ·Sᵢ` over rotating machines
(inverter-based resources contribute zero), then `H_tot = H_eq + H_loads`. Load
inertia is uncertain, so `H_tot` is given as a **range**, not a point value.

| System            | KE (MWs) | H_tot (s)   |
|-------------------|---------:|:------------|
| Spain             |   97,590 | 2.17 – 2.67 |
| Portugal          |   21,884 | 2.45 – 2.95 |
| Iberian Peninsula |  119,474 | 2.21 – 2.71 |

The report's stated modelling assumptions (pp.35–36):

- Inverter-based resources (batteries, wind, PV) contribute **no** inertia.
- Thermal solar and some other renewables have **non-zero** inertia constant.
- For inverter-based resources, rated power ≈ delivered active power.

*(derived)* `S_base = KE / H_tot`, so the Iberian base implied by the range is
44,086 – 54,061 MVA (48,567 MVA at the midpoint `H_tot = 2.46 s`). The absolute
swing relation `RoCoF = f0·ΔP / (2·KE)` is independent of that base choice, which
makes KE the safer number to key a scenario off.

### 1.2 Interconnection state

- HVDC Santa Llogaia–Baixas: **2 × 500 MW, Spain → France**, in *constant power
  mode*; AC voltage setpoints 405 kV (ES end) / 395 kV (FR end) (p.122).
  Constant-power mode means the HVDC provides **no** frequency support.
- ES–PT flow ≈ **750 MW**, ES–MA flow ≈ **2,100 MW**, both stable through the
  pre-event period (p.120).
- ES–FR active power fell by ≈ **1,500 MW** between 12:32:00 and 12:33:00 (p.120).
- Iberian exports peaked around **5 GW** during the morning (p.9).

### 1.3 Voltage

- 400 kV operating limits: **435 kV upper / 360 kV lower**;
  220 kV limits: **246 kV / 198 kV** (Fig 3-4, p.111).
- The 400 kV network stayed below 435 kV until the event sequence (p.9).
- 12:32:58 — positive-sequence magnitudes over 1.05 pu (p.109).
- 12:33:17 — maximum 442.5 kV = **1.106 pu** (p.109).
- 12:33:18 — maximum 451.4 kV = **1.128 pu**, highest in southern Spain (p.109).

### 1.4 Oscillations (context — not reproducible at M1)

- 12:03–12:08: local mode, dominant frequency **0.63 Hz** (p.10).
- 12:19–12:22: inter-area East-Centre-West mode, **0.21 Hz** (p.10).
- Damping of the ECW mode degraded from ≈1.71 % (12:07:23) and went **negative**
  around 12:19, recovering to ≈2.03 % by 12:31:23 (Fig 2-66, p.64).
- Before 12:03 no oscillation above 20 mHz amplitude was detectable (p.9).

### 2.1 Cascade magnitude for a ramp model *(derived)*

A model that represents the fast cascade as a **ramp** rather than as discrete
trips (GridSim M3 step 5) needs one number for how much generation the ramp
carries, and one for how long it takes. Both are derived here, from the table
above, because two figures for the first quantity were previously in circulation
that differ by 1.87x and neither was reconstructible.

**What the number is.** *Generation lost* — not apparent imbalance. Those are
different quantities in this event by more than the correction below: at the
moment -1 Hz/s was reached the Iberian imbalance was >=6,150 MW, of which
~5,000 MW was the **export swing** from loss of synchronism (§2.3). A two-area
model produces that swing itself, so feeding an imbalance figure into the ramp
would count it twice.

**Magnitude, two routes.**

| route | arithmetic | MW |
|---|---|---:|
| pre-cascade generation loss (clusters 2, 3 — gone by 12:32:57.220) | 208 + 355 | 563 |
| **top-down**: report cumulative for Spain at 12:33:20.560, less the pre-cascade loss | 5,750 - 563 | **5,187** |
| **bottom-up**: Table 3-1 clusters 4a…13, summed | 582+145+930+650+2,600 | 4,907 |

The bottom-up sum is a **floor**, because the 7–13 row is stated as >=2,600 MW.
It falls 280 MW short of the top-down figure, which sits inside that `>=`. The
same itemisation is also short at the report's earlier checkpoint — clusters
2…5b sum to 2,220 MW where the report states >2.5 GW by 12:33:18.020 — so the
shortfall is a property of Table 3-1's coverage rather than of this particular
subtraction, and the report explains it: generation below 1 MW has no real-time
reporting obligation, so the itemisation is a lower bound by construction (§5,
and p.102 fn.24).

**Duration.** 12:33:16.460 (cluster 4a, the first event of the fast cascade) to
12:33:20.560 (the report's own cumulative checkpoint, and the instant |RoCoF|
first reached 1 Hz/s) = **4.100 s**.

**Scope boundary.** The 5,750 MW is stated *for Spain* (p.119) and every cluster
in the table above is a Spanish site, whereas a two-area model's machine is
usually **Iberia**, keyed off the Iberian kinetic energy in §1.1. Portuguese
generation loss in the same window is not in Table 3-1 and is therefore not in
this figure.

**Two figures this replaces, neither of which is used.** 5,750 MW taken
unreduced counts the 563 MW of clusters 2 and 3 twice, since they were 19 s in
the past when the cascade began. 2,773 MW does not reconstruct from Table 3-1 by
any grouping. Both are carried as labelled cells of the sweep in
`scripts/iberia_two_area.jl`, which prints this arithmetic rather than quoting it.

### 2.3 RoCoF facts (pp.116–119)

- All reported RoCoF uses a **500 ms sliding window** (ENTSO-E best practice).
- |RoCoF| stayed within **1 Hz/s** until **12:33:20.560**, when f was already ≈49 Hz.
- The regulatory withstand threshold **−2 Hz/s** (Spanish TED 749/2020, Portuguese
  Portaria 73/2020) was reached at ≈**12:33:23.360**.
- At the moment −1 Hz/s was first reached, the Iberian imbalance was **≥6,150 MW**
  — of which ≈**5,000 MW was the export swing caused by loss of synchronism**,
  not by generation/demand imbalance. See the fidelity boundary in the plan doc.

## 5. What the report says it does **not** know

Useful because it bounds what any reproduction can legitimately claim:

- Causes of most trips are **unknown**; the report is explicitly factual-only,
  with root causes deferred to the final report (p.102).
- Not all events are time-synchronised to sufficient accuracy; the ordering
  inside the fast cascade is uncertain (p.102).
- Parts of the system are not fully observable — generation <1 MW has no
  real-time reporting obligation, so imbalances are estimated (p.102, fn.24).
- Inertia is "affected by significant uncertainty", hence the range (p.36).
